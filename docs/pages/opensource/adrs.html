Architecture Decision Records
16 accepted ADRs that govern all code. These are normative — the highest authority in the project. Read before contributing.

If your code contradicts an ADR, your code is wrong — not the ADR. Open an arch-conflict GitHub issue if you believe an ADR needs updating.

Defines the platform adapter pattern and why surface-specific code cannot live in components.
