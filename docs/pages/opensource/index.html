Project Governance

traCtl follows a maintainer-led governance model with a frozen architecture baseline.

DocumentAuthorityWhat it controls
ADRs (docs/adr/)HighestArchitecture decisions — cannot be overridden by code
Canonical specs (docs/spec/)HighWire formats, execution semantics
Terminology (docs/spec/00_terminology.md)HighVocabulary — no synonyms allowed
HLD (docs/spec/02_hld.md)MediumHigh-level design
RoadmapMediumPhase status and milestones
CONTRIBUTING.mdStandardDay-to-day contribution process

Conflicts resolve upward — if your code contradicts an ADR, the code is wrong, not the ADR. Open an arch-conflict issue if you believe an ADR needs updating.
