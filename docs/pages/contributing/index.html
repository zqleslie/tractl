Contributing to traCtl
The full CONTRIBUTING.md rendered here — always in sync with the repo root file.

Read before writing any code: traCtl has a frozen architecture and a phased roadmap. Contributing without reading the ADRs and the active phase guardrail in AGENTS.md will result in your PR being closed. This is not bureaucracy — the architecture constraints exist for good reasons documented in each ADR.

Setup in 4 commands

git clone https://github.com/tractl/tractl.git
cd tractl
make setup      # install git hooks — run once per clone
make install    # Go modules + npm deps
make build-cli  # verify everything compiles
make test       # verify all tests pass

Before every commit

make check   # vet + fmt-check + lint + test — must be green
