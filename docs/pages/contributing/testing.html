Go Test Structure

Table-driven tests (required for validators)

Every validator uses table-driven tests. New edge cases are added as new rows — no new test functions needed.

func TestStepKindValidation(t *testing.T) {
    tests := []struct {
        name    string
        kind    string
        wantErr bool
    }{
        {"valid request kind", "request", false},
        {"valid script kind",  "script",  false},
        {"unknown kind",       "unknown", true},
        {"empty kind",         "",        true},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            err := validateStepKind(tt.kind)
            if (err != nil) != tt.wantErr {
                t.Errorf("got err=%v, wantErr=%v", err, tt.wantErr)
            }
        })
    }
}

Dependency injection for engine tests

The engine accepts interface implementations in engine.Config. Tests inject stubs without mocking HTTP.

// engine_test.go — inject stub planner
cfg := engine.Config{
    WorkflowFile: "testdata/minimal.yaml",
    Planner: &stubPlanner{   // implements engine.Planner
        plan: fixedExecutionPlan,
    },
}

Frontend Testing

Vitest handles unit and component tests. Playwright handles E2E tests that exercise the full WASM bridge.

Run make build-wasm before running Playwright tests — the E2E tests require the compiled tractl.wasm file in frontend/public/.
