What is traCtl?

traCtl is a Git-first API workflow execution and validation platform. You define HTTP workflows as YAML/JSON files — steps that depend on each other, pass data between them, assert on responses, and run custom scripts. The same workflow definition runs identically across CLI, browser (WebAssembly), native desktop, and CI.

Define API workflows as YAML/JSON files — declarative, DAG-aware, with a sandboxed scripting engine — all in a single Go binary.

Roadmap Status

traCtl follows a phased implementation roadmap. Architecture is frozen — read the ADRs before writing any code.

Phase 1–6 Contract enforcement, parsing, overlay, planning, compilation, HTTP execution Complete
Phase 8–9 Script sandbox, assertion engine, extract engine, retry, hooks Complete
Phase 7 Diagnostics and reporting — TOON output formatter, per-step diagnostic directives In Progress
UI Track Web Surface Foundation — persistence, status bar, server Tier 2 In Progress
Phase 10+ Provider plugins, extension platform, acquisition layer Not Started

🛠️ Essential Make Targets

make install — Go modules + npm deps
make build-cli — build CLI binary
make dev-web — WASM + Vite dev server
make check — vet + lint + test (CI gate)
make sync-docs — sync markdown to _raw/
